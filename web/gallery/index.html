數位孿生機台選一台機器，在瀏覽器裡用 Python 控制它

使用說明

每一台都是完整的數位孿生：3D 機台、PLC 暫存器表（%Q 輸出、%I 輸入），以及右側的 Python 編輯器。不用安裝任何東西，打開就能寫程式讓機台動起來。

  1. 1選一台機器按「進入」
  2. 2右側「載入範例」挑一段程式
  3. 3按「執行」（Ctrl+Enter）看機台動
  4. 4改程式、或開「暫存器表」手動切換

建議順序：產線（I/O 與步進程序）→ 雙軸模組（位置伺服）→ 三軸龍門（直線插補、同步軸）→ 並聯機器人（運動學）。

模擬沒有真實的力與極限開關，超出行程只在 Python 端擋。本機 Python 模式請看各機台的「使用說明」。

產線模型改作自 Preliy/DT_PSA_OPCV（GPL-3.0）；其他機台由第三方 STEP 以 CAD 流程自動轉出。
